📑 理论基石与前沿文献调研

StatLLM 建立在近两年安全与 NLP 顶会对“黑盒大语言模型指纹与数字偏置归因”的严谨科学发现之上。

arXiv 2026 核心文献 查看论文 ↗

One Token Is Enough: Fingerprinting and Verifying Large Language Models from Single-Token Output Distributions

Tomáš Bruckner (2026.07) | 开源项目: ToseaAI/llm-fingerprint-detector

论文核心结论：大语言模型缺乏真正的物理熵，当被要求生成“1到100之间的随机数”时，其单 Token 输出具有稳定的非均匀偏好（Numeric Generation Bias）。通过比较经验离散分布的 Jensen-Shannon 散度与多项似然，仅需几十次简单查询即可精准验证 API 是否存在偷梁换柱或静默量化。

USENIX Security 2025 查看论文 ↗

LLMmap: Fingerprinting For Large Language Models

Dario Pasquini, Evgenios M. Kornaropoulos, Giuseppe Ateniese

论文核心结论：设计如同网络安全 nmap 一样的主动探测器。通过策略性地向集成了大模型的应用发送 3~8 个探针，分析模型在安全对齐、边界违规与特定格式遵从下的行为足迹，即便目标包裹了复杂 System Prompt，准确率仍超 95%。

NAACL / ICLR 2025 Security Research

LLMPrint: Behavioral Fingerprinting of Large Language Models via Prompt Injections

论文核心结论：利用“忽略所有提示词……”等覆写探针，击穿前端人设包装，强迫模型暴露底层预训练分词器偏好与内置 RLHF 反应。

📐 StatLLM 核心数理模型

1. 狄利克雷平滑条件概率 (Dirichlet-Smoothed Categorical Prob):
P(s | q, M) = (C_q(s) + α) / (Total_q + α * |S_q|), 其中 α = 0.5 (Jeffreys Prior)

2. 联合对数似然 (Joint Log-Likelihood for n₂ answers):
log L(M | D) = ∑_{i=1}^{n₂} log P(s_i | q_i, M)

3. Log-Sum-Exp 归一化后验概率 (Posterior Prob):
P(M_k | D) = exp(log L(M_k) - max_j log L(M_j)) / ∑ exp(log L(M_l) - max_j log L(M_j))

4. Bootstrap 95% 置信区间 (Bootstrap Confidence Interval):
对 n₂ 个观测有放回重采样 B=800 次，取各模型后验概率向量的 2.5% 与 97.5% 分位数。
